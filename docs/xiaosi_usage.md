# 小思使用说明（给人看的，一页）

小思是一条会听话的机械臂：你叫它，它先问清楚，你说「小思确定」它才动手，说「小思停下」它马上停。

## 一、开之前（每次开机做一遍）
1. 机械臂通电，**旁边站一个人**，手能够到电源键。
2. 关掉会占着机械臂的程序：录制页面（8768）、5050 数字孪生、`ui/dev/mock_arm.py`（假臂页面，占着 8000 口）。
3. 想要自由聊天：把小米 MiMo 的 key 写进 `~/.xiaosi_mimo_key`（只写一行 key，`chmod 600`）。**不要发到微信或仓库里。** 不写也能用，只是不能聊天。

## 二、启动
在 MacBook 的「终端」App 里（麦克风权限跟着终端走）：
```bash
cd ~/Documents/sukesong-2026
tools/xiaosi_start.sh          # 正式用
FAKE=1 tools/xiaosi_start.sh   # 演练：说话、页面、按钮、先问再动全走一遍，动作是假的（等 6 秒算做完），臂不动
DRY=1 tools/xiaosi_start.sh    # 只看唤醒词认得对不对：只打印，页面没反应
```
- 改页面、练台词、给人演示流程，都用 `FAKE=1`。
- 浏览器会全屏打开小思的眼睛页面：http://127.0.0.1:8000/
- 终端第一行会写「自由对话：开」或「关」。
- 退出：在终端按 `Ctrl+C`。

## 三、怎么叫它
说「**小思小思**」或「**小思同学**」，它答「我在呢」，屏幕上的眼睛睁开。
它没人理一会儿会打瞌睡（眼睛眯起来），再叫一声就醒。

## 四、让它做事
| 你说（或按页面按钮） | 小思会怎样 |
|---|---|
| 小思递杯子 / 〔递杯子〕 | 先问「要我去拿水杯吗？…然后说：小思确定」 |
| 小思拿零食 / 〔拿零食〕 | 先问，再等「小思确定」 |
| 小思握手 / 〔握手〕 | 先问「要和我握握手吗？…」，再等「小思确定」 |
| **小思确定** / 〔确定〕 | 开始动手。**问完 15 秒内**要说，过了就不算 |
| 小思取消 / 〔取消〕 | 不做了 |
| 小思松手 / 〔松手〕 | 夹爪张开（递到你手里后用） |
| **小思停下** / 〔停〕 | **随时**停下，臂停在当前位置不松劲 |

说「小思确定」之前，**先看一眼臂周围有没有人**。

**换模型**：页面右上角点「模型」，每个动作一个下拉框（握手 1 万 / 2 万步；杯子 ACT / SmolVLA；零食合训 / 薯片单训）。没下载的模型选不了；正在干活时不能换；换完下一次动作就用新的。握手换了模型，先在终端对它跑一次 `tools/skills/shake_model_lab.py --sim --model act_v3_010000`。

## 五、自由聊天（要有 key、要联网）
叫醒后 **6 秒内**随便说一句，比如「你是从哪里来的呀」「能帮我拿杯水吗」。
- 问的是要做的事（水、零食、握手、停）→ 照第四节走，照样要「小思确定」。
- 别的话 → 小思用自己的口气回答，屏幕上出字幕。**聊天从来不会让臂动。**
- 一轮大约 8–10 秒才开口（听写 + 想 + 说），别着急。

## 六、握手第一次用：先仿真
握手前要先在电脑里试一遍（3 小时内有效），不然小思会说「握手还没在电脑里先试过，我先不伸手」：
```bash
tools/skills/shake_model_lab.py --sim
```
浏览器开 http://127.0.0.1:5051 看 3D 臂怎么动。终端写「仿真通过」、3D 里看着像伸手握手，才上真机。

## 七、停下和收臂
- 停：说「小思停下」、按页面〔停〕、或终端 `Ctrl+C`。**真出事就按电源键。**
- 握手中途停下后，臂会停着不动（测试台抱着它）。收臂：**扶住臂**，再跑
  `tools/skills/shake_model_lab.py --release`（回到零位并松开串口）。之后才能递杯子。

## 八、常见问题
| 现象 | 怎么办 |
|---|---|
| 叫不醒 | 离麦克风近一点，四个字连着说，别太快 |
| 它说「这次没做好，…有程序占着…」 | 关掉录制页面 8768 / 5050 孪生 / 轨迹回放 8792，或握手后先 `--release` |
| 它说「握手还没在电脑里先试过」 | 跑第六节的 `--sim` |
| 自由聊天没反应 | 看终端第一行是不是「自由对话：开」；没开就是 key 没写或没网 |
| 页面空白 | 手动打开 http://127.0.0.1:8000/ |
| 它自己的话里有「小思确定」 | 不会误触发：小思说话时和说完 1 秒内，只认「小思停下」 |

## 安全线（不能破）
1. 动臂时旁边必须有人。
2. 先问再动：只有「小思确定」或〔确定〕能让它动手。
3. 一次只开一个控制机械臂的程序。
4. 机械臂读数出现 999 = 没收到回话，马上停。
