# 小思「看着你」：不标定的找人和跟人

一句话：**不算人在房间里的坐标，只看人脸在画面里偏左还是偏右，偏哪边就往哪边转一点。** 看一眼、转一点、再看一眼，是闭环，所以相机装歪一点、没标定都不要紧。

## 两层
| 层 | 用什么 | 动什么 | 代码 |
|---|---|---|---|
| 眼睛跟人（一直开） | 屏幕上方的相机（FaceTime 或第三视角） | 只动屏幕上的眼珠，不碰臂 | `tools/eyes/face_watch.py` → 臂服务 `/look` → `ui/xiaosi.html` |
| 臂跟人（演示时开） | 腕上相机（深度桥 8767 彩色 + 8766 深度） | 只转底座 joint1 | `tools/eyes/arm_follow.py` |

找人脸用 YuNet（OpenCV 自带接口，MIT 许可的 300 KB 小模型），没有就退回 Haar。CPU 上每帧几毫秒，不需要显卡。

## 臂跟人怎么走（arm_follow.py）
1. **扫**：底座在起始角左右各 0.5 rad 内慢慢来回转（每秒 0.15 rad），腕上相机一直找人脸。不用提前录轨迹。
2. **锁**：连续 2 帧看到人脸就停止扫描，改成小步跟：人脸偏离画面中线超过 8% 才转，每步最多 0.02 rad，总范围不超过起始 ±0.6 rad。
3. **丢了**：1.5 秒看不到人脸，回去扫。
4. **安全**：深度相机中心距离 < 40 cm（人凑太近）就不动；`Ctrl-C` 或建一个文件 `/tmp/xiaosi_estop` = 急停锁定（在当前位置保持，不松力），然后退出。
5. **方向**：唯一要定的是 `--sign`。先干跑（不动臂），人站到画面右边，看打印的转向对不对，反了就用 `--sign -1`。

```bash
PY=~/Documents/CodeX_agent/Moonstone_Hackathon/vla/.venv/bin/python
$PY tools/eyes/arm_follow.py                    # 干跑：只读腕上相机，打印会怎么转
$PY tools/eyes/arm_follow.py --real --sign 1    # 真动臂：人在旁边，先停掉其它占串口的程序
touch /tmp/xiaosi_estop                         # 急停锁定
```
在 Mini 上用录好的腕部视频测过：622 帧里 84 帧找到人脸，扫 → 锁切换正常，每步都没超过 0.02 rad。

## 和语音、动作的关系（演示流程）
**追踪 → 唤醒 → 交互**：人走进来，眼睛（和臂）转过去看着他 → 他说「小思小思」→「我在呢」→「小思递杯子 / 小思拿零食 / 小思握手」→ 小思先问 → 「小思确定」→ 动手。

臂跟人和动作技能都要独占串口，**同一时间只能开一个**。现在臂跟人是单独的演示命令（拍视频用）；要做成「叫醒时自动停跟人、再执行动作」，需要把它也写成 `config/skills.json` 里的一个技能，并让臂服务在开新技能前先停它。
